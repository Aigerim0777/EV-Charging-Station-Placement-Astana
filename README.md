# GIS-Based Spatial Analytics for Optimal Electric Vehicle Charging Station Placement

## Project Overview

This repository supports Assignment 3 (Results Section) for the Research Methods and Tools course.

The study investigates suitable locations for public electric vehicle (EV) charging stations in Astana, Kazakhstan, using Geographic Information Systems (GIS) and Multi-Criteria Decision-Making (MCDM).

The research compares three weighting approaches: Equal Weights, Entropy, and CRITIC. It also evaluates spatial suitability, candidate-zone rankings, sensitivity to criterion weights, and agreement with existing charging stations.

## Dataset

The analysis uses an OpenStreetMap (OSM) GeoJSON export containing 37,917 geographic features.

The pilot study focuses on a reduced area of Astana. An H3 resolution-9 hexagonal grid was generated for spatial analysis.

The dataset processing produced:

- 478 initial H3 cells
- 259 excluded cells
- 219 eligible cells
- 30 mapped charging station records in the study area
- 23 eligible charging station records occupying 22 H3 cells

Five spatial criteria were evaluated:

- C1: Distance to main roads
- C2: Distance to public parking
- C3: Density of points of interest
- C5: Distance to electrical substations
- C7: Distance to fuel stations

Population density (C4), land-use suitability (C6), expert-based AHP weighting, and slope screening were not implemented in this reduced pilot.

## Methodology

The analysis was conducted in Python using the following methods:

- GIS-based spatial processing and H3 hexagonal indexing
- Min-max normalization of spatial criteria
- Equal, Entropy, and CRITIC criterion weighting
- Weighted linear combination for suitability scores
- Spearman rank correlation and Jaccard similarity
- TOPSIS for candidate-zone ranking
- Sensitivity analysis with 120 weight-perturbation scenarios
- ROC-AUC and hit-rate validation against mapped charging stations
- Spatial-block bootstrap confidence intervals

The analysis uses random seed 42 for reproducibility.

## Main Results

The following principal validation results were reproduced using the Python reconstruction:

| Method | AUC | Hit Rate |
|---|---|---|
| Equal Weights | 0.7231 | 60.9% |
| Entropy | 0.7037 | 69.6% |
| CRITIC | 0.7248 | 69.6% |

The pilot contains 219 eligible H3 cells and evaluates 120 sensitivity scenarios.

The confidence intervals obtained from the reconstructed implementation differ slightly from some values reported in the article. The complete permutation-testing and Holm-adjustment procedure has not yet been implemented in the available script.

These results are preliminary and apply only to the reduced study area.

## Repository Files

- `export.geojson` — OpenStreetMap geographic dataset used in the analysis.
- `analysis.py` — Python script reconstructing the pilot analysis.
- `requirements.txt` — Python dependencies.
- `README.md` — Project documentation.
- `cells.csv` — Calculated spatial criteria and suitability scores.
- `weights.csv` — Calculated criterion weights.
- `zones.csv` — TOPSIS candidate-zone rankings.
- `agreement.csv` — Ranking agreement results, generated by the script.
- `sensitivity.csv` — Weight sensitivity scenarios.
- `sensitivity.pdf` — Sensitivity analysis visualization.
- `validation.csv` — AUC and hit-rate results.
- `validation_sample.csv` — Cells used for validation.
- `comparison.json` — Comparison between reconstructed and article-reported values.

The currently uploaded result files are stored in the repository root. The script generates its new outputs in the `results/` directory.

## Installation

The analysis can be executed locally or in Google Colab.

Install the required Python packages:

```bash
pip install -r requirements.txt
```

## Running the Analysis

Execute the Python script using the provided dataset:

```bash
python analysis.py --input export.geojson --output results
```

The script generates spatial suitability scores, criterion weights, TOPSIS rankings, sensitivity results, validation statistics, and comparison outputs in the `results/` directory.
